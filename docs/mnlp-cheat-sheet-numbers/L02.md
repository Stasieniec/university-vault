# MNLP L02 Multilinguality and Writing Systems: numbers taken off the flashcards (2026-10-08)

Raw material for the exam cheat sheet. Values as stated in the lecture note.

- Languages: over 7,000 in total; more than 100 with over 10 million speakers.
- Dutch: about 24 million speakers, yet only medium resource.
- ASCII: 128 codes (1963).
- Unicode code space: 17 x 65,536 = 1,114,112 codepoints (U+0000 to U+10FFFF); over 150,000 assigned; 168 scripts.
- Planes: 0 BMP (0000-FFFF); 1 SMP (emoji); 2 SIP; 3 TIP; 14 SSP; 15-16 private use.
- UTF-8 ranges: up to U+007F 1 byte (7 payload bits); up to U+07FF 2 bytes (11); up to U+FFFF 3 bytes (16); up to U+10FFFF 4 bytes (21).
- UTF-8 lead bytes: 0xxxxxxx, 110yyyxx, 1110yyyy, 11110zzz; continuation byte 10xxxxxx.
- Worked encodings: é U+00E9 = C3 A9; 中 U+4E2D = E4 B8 AD; grinning face U+1F600 = F0 9F 98 80.
- Byte inflation in UTF-8: "hello" 1.0x, "café" 1.25x, "中文" 3.0x.
- "café": 4 codepoints in NFC, 5 in NFD; NFD bytes 63 61 66 65 CC 81 (6 bytes).
- Bytes per codepoint: UTF-8 1-4, UTF-16 2 or 4, UTF-32 exactly 4.
